# מדריך הרצה מקומית — JACO-PIM

המדריך מסביר איך להריץ את JACO-PIM על המחשב שלך ולחבר אותו ל-Supabase.

---

## שלב 0 — כלים שצריך להתקין פעם אחת

| כלי | למה | קישור |
|-----|-----|-------|
| **Node.js** (גרסת LTS) | מריץ את הפרויקט (כולל `npm`) | https://nodejs.org |
| **Git** | מסנכרן קוד עם GitHub | https://git-scm.com/downloads |
| **VS Code** (עורך קוד) | לעריכת הקוד (מומלץ) | https://code.visualstudio.com |

בדיקה שהכל הותקן — פתח טרמינל (ב-Windows: "PowerShell"; ב-Mac: "Terminal") והקלד:

```bash
node -v    # אמור להציג מספר גרסה, למשל v22.x
npm -v
git -v
```


## שלב 2 — להתקין את התלויות

מתוך תיקיית הפרויקט:

```bash
npm install
```

---

## שלב 3 — ליצור פרויקט Supabase

1. היכנס ל-https://supabase.com והתחבר (אפשר בחינם).
2. לחץ **New project**, תן שם (למשל `jaco-pim`) ובחר סיסמה ל-DB.
3. אחרי שהפרויקט נוצר, היכנס ל-**Project Settings → API** והעתק שלושה ערכים:
   - **Project URL**
   - מפתח **anon public**
   - מפתח **service_role** (סודי! לא לחשוף)

---

## שלב 4 — להגדיר את החיבור (`.env.local`)

בתיקיית הפרויקט, צור קובץ בשם `.env.local` (אפשר להעתיק מ-`.env.example`) ומלא:

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR-PROJECT-ref.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=המפתח-anon-שלך
SUPABASE_SERVICE_ROLE_KEY=המפתח-service-role-שלך
```

> הקובץ `.env.local` לא נשמר ב-Git (הוא מוסתר בכוונה כדי לא לחשוף סודות).

---

## שלב 5 — להריץ את מבנה בסיס הנתונים (המיגרציה)

ב-Supabase, היכנס ל-**SQL Editor**, פתח שאילתה חדשה,
העתק לתוכה את כל התוכן של הקובץ `supabase/migrations/0001_init.sql`
מהפרויקט, ולחץ **Run**. זה יוצר את כל הטבלאות (מוצרים, קטגוריות,
מאפיינים, וריאנטים, מדיה).

---

## שלב 6 — להריץ את האפליקציה

```bash
npm run dev
```

פתח בדפדפן: **http://localhost:3000**

עכשיו דף המוצרים יתחבר ל-Supabase במקום להציג "Supabase לא מחובר".
