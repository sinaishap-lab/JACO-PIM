# חיבור ל-iCount — סנכרון רשימת המוצרים

JACO-PIM הוא מקור האמת למוצרים. הסנכרון **דוחף** את קטלוג המוצרים ל-iCount
כפריטים (items), לפי המק"ט — מוצר/וריאנט חדש נוצר, וקיים מתעדכן.

## מה מסונכרן
- **מוצרי קצה** בלבד (לא חומרי גלם).
- מוצר עם גדלים/צבעים → **פריט לכל וריאנט** (לפי מק"ט הווריאנט, מחיר לכל גודל).
- מוצר ללא וריאנטים → פריט אחד (מק"ט המוצר, מחיר המכירה).
- מיפוי שדות: `sku` ← מק"ט, `description` ← שם, `unitprice` ← מחיר מכירה.

## הגדרה (פעם אחת)
הוסיפו ל-`.env.local` את פרטי ה-API של iCount:

```
ICOUNT_CID=מזהה_החברה
ICOUNT_USER=שם_משתמש_API
ICOUNT_PASS=סיסמת_API
# אופציונלי: ICOUNT_API_URL=https://api.icount.co.il/api/v3.php
```

> את הפרטים מוצאים ב-iCount תחת הגדרות → API. **אל תכניסו אותם לקוד או ל-Git.**

## שימוש
בעמוד **מוצרים** יש כפתור **"סנכרון ל-iCount"**. לחיצה דוחפת את כל הקטלוג ומציגה
סיכום (כמה נוצרו / עודכנו / שגיאות).

## הערות
- הסנכרון רץ בצד-שרת מול ה-API של iCount — הריצו אותו **מקומית** (ה-API חסום
  מסביבת הענן).
- אם שמות השדות אצלכם ב-iCount שונים, עדכנו את `toIcountFields` ב-
  `lib/integrations/icount/sync.ts`.
- זו גרסה ראשונה (דחיפה בלבד). אפשר להרחיב בהמשך: יצירת חשבוניות/הזמנות, משיכת
  לקוחות וכו'.
